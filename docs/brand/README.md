# Brightverse Academy brand

The mark is an open book with a bright eight-point star rising from its fold:
"bright" is the star, "verse" is the page.

| File | Use it for |
| --- | --- |
| `brightverse-logo.svg` / `.png` | The main logo on white or light backgrounds: website header, invoices, documents, email signatures |
| `brightverse-logo-dark.svg` / `.png` | On dark backgrounds or photos: social covers, slides |
| `brightverse-logo-stacked.svg` / `.png` | Square spaces: profile pictures with the name, certificates, posters |
| `brightverse-mark.svg`, `brightverse-mark-512.png`, `-192.png` | The mark alone: app icon, social profile picture, WhatsApp Business photo |
| `brightverse-mark-plain.svg` | The mark without its green tile, on white |
| `favicon.ico` | Browser tab icon |
| `icons/*.svg` | The app's line icons (24 × 24, 1.8 px stroke, drawn in ink #17211D) for slides and documents |

SVG files stay sharp at any size; use them when the place accepts SVG. The
name in the logos is drawn as outlines, so they look the same without the font.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Brightverse green | `#1D6A50` | Main color: buttons, links, the logo tile |
| Deep green | `#123F30` | Dark backgrounds |
| Bright gold | `#F2B53A` | The star; highlights and small shapes. Not for text on white (too light to read) |
| Ink | `#17211D` | Text |
| Paper | `#F6F6F2` | Page background |

## Type

**Plus Jakarta Sans** (free, Google Fonts). Headings 700–800, text 400–500.
The word ACADEMY is set in capitals, 700, with wide letter spacing.

## Keep it clean

- Leave space around the logo at least as wide as the star.
- Don't stretch it, recolor the star, or put the green tile on a green background.
- Smallest size: the mark at 16 px, the full logo at 120 px wide.

`make-logo.py` regenerates the SVG files (instructions at the top of the file).
